| 0.11.0   | 2026-09-10    | (1) New backbones. MobileOne, MobileNetV4 (incl. Hybrid attention variants), FastViT, RepViT — all published sizes, verified against official/independent reference implementations, structural reparameterization support for MobileOne/FastViT/RepViT.<br />(2) New segmentation decoders. LR-ASPP, PP-LiteSeg (with UAFM), DDRNet (with DAPPM) — pluggable with any registered backbone.<br />(3) New losses. Lovász-Softmax, boundary loss, structure loss, log-cosh Dice, OHEM cross-entropy, class-balanced weighting helper, deep-supervision loss aggregation, Quality/Distribution/VariFocal loss, CIoU/SIoU `iou_box_coef` modes; finished the previously-stubbed `combo_loss`.<br />(4) New optimizers. Lion, SAM (Sharpness-Aware Minimization) wrapper.<br />(5) New classification building blocks. `multilabel_classifier`, `ordinal_classifier` (CORAL-style), GeM/ECA/CoordAtt-lite attention-pooling layers wired into the existing classifier heads via `pre_pool_attention`.<br />(6) New lightweight anchor-free object detection module (`_model_detection.py`): FCOS-lite head, PAFPN-lite neck, ATSS label assignment, NMS-based inference.<br />(7) New metrics. `BoundaryFScore`, `MeanAveragePrecision`.<br />(8) New `swiss_army_keras/inference_utils.py`: test-time-augmentation (`tta_predict`) inference helper.<br />(9) Rewrote `optimizers.py` (`Yogi`, `RectifiedAdam2`, `AdaBeliefOptimizer`, `AdaHessian`) against the modern `tf.keras.optimizers.Optimizer` API; bumped to `tensorflow>=2.16` with `TF_USE_LEGACY_KERAS=1` forced (required for QAT under Keras 3).<br />(10) Refactored `_backbone_zoo.py` around a central `BACKBONE_REGISTRY`, removing the previous `eval()`-based dispatch.<br />(11) Bugfixes: `deeplab_v3_plus(backbone=None)` shape mismatch; `MobileNetV3Large`'s non-deterministic layer-name lookup; `GELU`/`Snake` missing `register_keras_serializable`; `utils.py`'s `dummy_loader` undefined-name `NameError`; dead `sklearn` imports; bare `except:` clauses; declared several previously-undeclared runtime dependencies (`scipy`, `opencv-python`, `albumentations`, `matplotlib`, `scikit-image`, `tqdm`, `dill`). Full test suite: 270 tests across `tests/`. |
| Unreleased (after 0.11.0) | | (1) New architectures. PIDNet and PP-MobileSeg segmentation networks, StrideFormer backbone, GFL-lite detector (Ghost-PAN neck, SimOTA and DSLA assigners), YOLACT-style instance segmentation on FCOS-lite, monocular depth heads (`lr_aspp_depth`, `fastdepth_head`), keypoint regression and re-identification heads, optional image-quality side head.<br />(2) New utilities. `ood_utils` (Mahalanobis out-of-distribution scores), `iqa_utils`, `uint8_input_wrapper`, energy-score outputs, mixed-precision support.<br />(3) Pretrained weights. Conversion scripts for MobileOne, MobileNetV4, FastViT and RepViT (`scripts/port_*_weights.py`), numerically verified against `timm`.<br />(4) Packaging. `python_requires>=3.9`; `tensorflow_hub` declared; `typeguard` dropped; EfficientNet-Lite moved to the `[efficientnet-lite]` extra; `[porting]`, `[docs]`, `[test]` extras; `swiss_army_keras.__version__`.<br />(4b) Deployment. New `deploy_utils` module: deployment profiles (`default`, `litert-cpu`, `artpec7`, `artpec8`, `artpec9`), `reparameterize_model` (fuses MobileOne / RepViT / FastViT backbones inside any model), `strip_qat`, `convert_to_tflite`, `lint_tflite`. `Quantizer` gains `profile`, `reparameterize`, `strip_qat`, `strict` and reports `lint_report`; `TrainingDriver` gains `export_profile`. **Export now fuses reparameterizable backbones by default**, and strips QAT wrappers for integer-only profiles.<br />(5) Behaviour changes. Importing the package with Keras 3 active now raises `ImportError`; data loaders accept `seed=` for a reproducible split and decode any image format; `sppm_module` raises a clear error for inputs smaller than 128x128.<br />(6) Bugfixes. `freeze_layers` shared mutable default; `TrainingDriver` never saved its metric plots with the default name; data-loader pickling; wrong docstrings on `deeplab_v3_plus`, `deeplab_v3_plus_lite` and `unfreeze_model`.<br />(7) Tests and docs. Full-integer TFLite export tests (`pytest -m slow`); getting-started, model-zoo and deployment guides; docstrings for the training driver, quantizer and data loaders; complete API reference; `ASSESSMENT.md`, `EDGE_AI_CANDIDATES.md`, `ROADMAP.md`, `CONTRIBUTING.md`. |
