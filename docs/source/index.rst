swiss_army_keras
================

A Keras library for building, training and exporting compact vision models
for edge and IoT devices: pretrained-backbone plumbing, lightweight
segmentation / detection / classification heads, losses and optimizers for
hard and imbalanced data, a training driver, and quantized TFLite export.
